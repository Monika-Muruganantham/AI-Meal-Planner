# 🍽️ AI Meal Prep Assistant

## 📌 Overview
This project is an AI-powered Meal Prep Assistant built using AWS PartyRock. It generates personalized meal plans based on user preferences such as diet type, calorie goals, budget, and restrictions.

## 🚀 Features
- Personalized meal planning
- Nutrition insights (calories, protein, etc.)
- Grocery list generation
- Budget-based meal optimization

## 🧠 Tech Stack
- AWS PartyRock
- Prompt Engineering

## ⚙️ How It Works
1. User inputs preferences (diet, calories, budget)
2. AI processes constraints
3. Outputs structured meal plan + grocery list

## 🔮 Future Scope
- Integrate machine learning for recommendations
- Add user tracking and analytics
- Convert to full-stack web application
